# Política de seguridad

## Versiones con soporte

Solo la última versión publicada recibe correcciones de seguridad. Mantén activada la actualización automática (Ajustes → Actualizaciones).

## Informar de una vulnerabilidad

**No abras una incidencia pública.** Usa el aviso privado de GitHub: pestaña *Security* → *Report a vulnerability* de este repositorio.

Incluye qué versión usas, cómo reproducirlo y qué impacto tiene. Responderemos lo antes posible y publicaremos una versión corregida antes de dar detalles.

Las medidas de seguridad de 7Factura están descritas en [docs/seguridad.md](docs/seguridad.md).
